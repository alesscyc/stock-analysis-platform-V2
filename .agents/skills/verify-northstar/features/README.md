# Northstar verification map

Read this index before choosing a proof. Baseline: English UI, fresh browser state, owned loopback origin. The default static preview uses fictional NVDA data; only chart/local preference paths work there. The automated fixture regression supplies all state for Paper/research recipes and tears itself down. Real provider behavior needs separately provisioned live services.

Use T3 preview for interactive static proofs and the existing agent-browser harness for automated fixture proofs. Prefer roles/labels, refresh snapshot refs after changes, and capture action plus resulting state and persistence. Never replace a UI action with a storage setter. Fixture fault injection is setup, not user-path evidence. Record each listed entry point as passed, failed, or untested; exercising one does not prove its alternatives.

- [Symbols and watchlist](symbols.md): direct/keyboard discovery, saved symbols, alternate chart entry points.
- [Charts](charts.md): intervals, persisted indicators, drawings, CSV; default acceptance recipe is MA 10 persistence.
- [Screener and backtest](research.md): list scans, skips, results, strategy reports with no account mutation.
- [Paper Account and order review](paper.md): review, confirmation, fills, modification, ownership, reset boundaries.
- [AI and workspace preferences](assistant-settings.md): unsubmitted drafts, language, mobile layout, settings.

Initial map covers five feature groups. Live IB routing, full technical-overlay geometry, Random Forest training, fundamentals accuracy, and every provider failure are not certified by these recipes. Extend map entries when verifying those paths. Code presence in `docs/features.md` is not proof.
